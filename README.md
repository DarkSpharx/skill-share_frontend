# SkillShare

## Description

SkillShare est une plateforme de partage de compétences qui permet aux utilisateurs de proposer, suivre et gérer des formations en ligne.

## Fonctionnalités

- Création et gestion de profils utilisateurs
- Publication, inscription et gestion de cours
- Système de messagerie entre utilisateurs
- Tableau de bord personnalisé pour chaque utilisateur

## Installation

Clonez le dépôt, installez les dépendances et lancez l'application :

```bash
git clone https://github.com/votre-utilisateur/skill-share.git
cd skill-share/frontend
npm install
npm start
```

## Technologies utilisées

- React
- Node.js
- Express
- MongoDB
